# Grok Social Media Skills

Six social media growth skills for Grok Bot (and any agent that reads `SKILL.md` files): plan, write, humanize and grow on X, LinkedIn, Instagram, TikTok, Facebook and Reddit.

Every skill keeps outgoing posts, replies, comments and DMs as **drafts until you approve them**, and never invents metrics or stories.

## Skills

| Skill | What it covers |
|---|---|
| [x-growth](skills/x-growth/SKILL.md) | Weekly plans, posts, threads, reply drafts, AI-tell scrub, profile audit |
| [linkedin-growth](skills/linkedin-growth/SKILL.md) | Posts, carousels, comments, reply sweeps, profile audits, founder story bank |
| [instagram-growth](skills/instagram-growth/SKILL.md) | Captions, carousels, Reel hooks, hashtag sets, comments and DMs, profile audits |
| [tiktok-growth](skills/tiktok-growth/SKILL.md) | Hooks, scripts, captions, hashtags, trend fit, profile audits |
| [facebook-growth](skills/facebook-growth/SKILL.md) | Page posts, replies, weekly plans, Page audits |
| [reddit-growth](skills/reddit-growth/SKILL.md) | Picking subreddits, checking rules, drafting posts and comments |

## Install in Grok Bot

Copy a skill folder into your skills library (for example `/home/box/agent-data/workflows/<skill-name>/SKILL.md`), or paste the `SKILL.md` into a new skill. Then ask your bot to "use the linkedin-growth skill".
